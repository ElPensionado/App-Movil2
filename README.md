# App-Movil2
Geoapp
Aplicación móvil de Android construida con Kotlin y utilizando el sistema de compilación Gradle.

Empezando
Estas instrucciones te ayudarán a tener una copia del proyecto funcionando en tu máquina local para desarrollo y pruebas.

Requisitos Previos
Necesitas tener instalado:

Android Studio (Recomendado)

Java Development Kit (JDK), como se referencia en gradle.properties y local.properties.
